The files from today

Session-1.5 demo snapshots (the five we used to tour the tools) — these ship with the LDaCA sample-data catalogue, so they import alongside the sample datasets in Wordflow. No separate download needed. In Data Loader → Import sample data, the modal's Demo Snapshots tab lets you select and import them any time.

Session-2 checkpoints (the QLD election tweet workflow, one workspace archive per phase) — these are workshop-specific. Download them from sih.tools/wordflow → Materials → Session 2 checkpoint files.

How to use them:

  • Demo snapshots: in the matching tool, click the camera icon → Load snapshot. The five we used are already in your snapshot list once you've imported demo snapshots in Wordflow.
  • Workspace archives (Checkpoint_*.zip): in Data Loader → Upload workspace → pick the file. You'll have a full reproduction of the workflow up to that checkpoint.

Sample data — and how to cite it

All three datasets are publicly available and ship as part of the sample-data catalogue (Data Loader → Import sample data in the app — the Datasets tab of the modal). They were supplied by LDaCA partner organisations. Please cite if used in published research.

Installing Wordflow on your own machine

Three options:

  1. Cloud (Binder) — same URL as today's workshop. Free, no install. Caveat: don't upload sensitive data.
  2. Desktop app (Mac / Windows) — native installer, runs everything locally. Recommended for serious work. Downloads: [link].
  3. Python (pip install ldaca-wordflow, or uvx ldaca-wordflow@latest to run directly) — for Python users, gives you CLI access. Requires Python 3.14+ and around 500 MB of disk.

The latest app and Binder links will always live at sih.tools/ldaca. The app will also notify you when a newer version is released; for most minor updates, downloading the slim installer and overwriting your existing install is all you need.
