The interface — 7 things to know

  1. Tool sidebar — pick a tool here
  2. Tool interface — controls and results for the selected tool
  3. Workspace graph view — your map of data blocks and their derivations
  4. Data viewer — click a block in the graph to see its rows
  5. Data block quick-select — switch the active block without going back to the graph
  6. Tutorial — every ? next to a control opens the matching section
  7. Feedback — tap anytime something is confusing, surprising, or broken

Session 1.5

5 tools, 5 minutes each

Touch every tool's destination — without setting any of them up.

Together — 5 minutes of setup

  1. Data Loader → Import sample content — import all three datasets.
  2. Data Loader → Import demo snapshots — import all five snapshots.
  3. Sidebar → pencil icon next to "VIEWS" — turn Snapshot Mode ON. This unlocks snapshot save/load in each tool. (A tool only becomes read-only after you load a snapshot into it; other tools keep working.)
  4. Workspace switcher → Create workspace — name it tour.

Once everyone has these four done, we tour the tools.

Tool 1 — Frequency

Same corpus, two lenses.

Load snapshot → Freq_Analysis_Newstalk.

  • Comparative view: left-leaning (Guardian + IA) vs right-leaning (Sky + PerthNow).
  • One corpus (newstalk_stories), filtered and grouped by source.
  • Spot words that are big on one side, small or absent on the other.

Tool 2 — Concordance

Three search patterns at once.

Load snapshot → SCL_Honi_Soit.

  • Regex: student\w*|staff|universit\w+ — each pattern coloured.
  • Dispersion view: per-document hits, colour-coded by which pattern matched.
  • Close reading at scale, three concepts in one query.

Tool 3 — Trends

One result, three stories.

Load snapshot → QLD_Election_Tweets_conc.

  • Concordance result over time: job\w* · lnp\w* · economic.
  • Switch grouping live: matched term · gender · party.
  • Coarsen the time bin (hour → day → week) — no rerun.

Tool 4 — Topic Modelling

Same corpus, themes this time.

Load snapshot → newstalk_left_vs_right.

  • Same newstalk data as Tool 1 — balanced 120 vs 121.
  • 8 topics, automatically discovered. Size = articles fit; distance = thematic similarity.
  • Colour-blended bubbles = shared themes across both sides. Solid = one side dominant.

Tool 5 — Quotation

Who said what?

Load snapshot → SCL_Honi_Soit.

  • ~870 quotations across 95 of 100 articles — student newspapers are quote-rich.
  • Click a row for the surrounding sentence and source.
  • Sort by speaker — see who gets quoted most.
  • English-only for now.

A real workflow

Six tools, one question, 45 minutes.

The research question

Did female and male candidates tweet about different topical issues during the 2020 QLD election?

Some moves I'll ask you to TRY THIS. Others WATCH ONLY.

If you fall behind, the Resources URL on the board has four checkpoint files. Load any one to rejoin in 30 seconds.

Phase A · WATCH ONLY

Load, join, slice

  1. Join QLD tweets + candidate gender data.
  2. Accept the dtype normalisation.
  3. Filter to gender = F, then gender = M → two sub-corpora.
  4. Filter each to text contains "#" — keep just the hashtagged tweets.

Three things to remember

  1. Workspace + data block + graph — your project is a tree of derived data.
  2. Tools talk to each other — left-click a word, add as block, detach, group. Stacking is what makes a workflow.
  3. Every tool is a lens — the analysis is shaped by how you shape the data, not by which tool you clicked.

The text flows. The lens changes.
