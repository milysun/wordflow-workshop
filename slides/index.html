The interface — 7 things to know

  1. Tool sidebar — pick a tool here
  2. Tool interface — controls and results for the selected tool
  3. Workspace graph view — where your current project's data and its analytical derivations live
  4. Data viewer — manage and inspect columns and rows in a data block. Not just a viewer.
  5. Data block quick-select — switch the active block without going back to the graph
  6. Tutorial — opens the tutorial index page; or click the icon next to any control to jump straight to its section
  7. Feedback — tap anytime something is confusing, surprising, or broken

Session 1.5

5 tools, 5 minutes each

Touch every tool's destination — you'll do the data prep yourself in Session 2.

Together — 5 minutes of setup

  1. Data Loader → Import sample data. The modal's two tabs import separately: on Datasets, select all three → Import selected; then switch to Demo Snapshots, select all five → Import selected again.
  2. Sidebar → pencil icon next to "VIEWS" — turn Snapshot Mode ON. This unlocks snapshot save/load in each analysis tool (Frequency, Concordance, Trends, Topic Modelling, Quotation). A tool's view goes read-only once you load a snapshot into it; other tools keep working.
  3. Data Loader → Create workspace — name it Wordflow. (Wordflow's hint system will highlight the button on first use. You'll keep this same workspace for the whole workshop.)

Once everyone has these three done, we tour the tools.

All datasets are publicly available LDaCA-partner contributions. Click the icon beside a dataset for its details and citation. Citations are also on the final slide — please cite if used in research.

Tool 1 — Frequency

Explore by comparison.

Load snapshot → Freq_Analysis_Newstalk.

  • Comparative view: left-leaning (Guardian + IA) vs right-leaning (Sky + PerthNow).
  • One corpus (newstalk_stories), filtered and grouped by source.
  • Switch between Cloud and List views — same data, different visual.
  • Spot words that are big on one side, small or absent on the other.
  • Right-click a word (cloud or list) to add it to stopwords — hides instantly.
  • Custom stopwords go to the top of the stopword list — remove one manually if you add a word by mistake.

Tool 2 — Concordance

Search several at once.

Load snapshot → SCL_Honi_Soit.

  • Regex: student\w*|staff|universit\w+ — each pattern coloured.
  • Dispersion view: per-document hits, colour-coded by which pattern matched.
  • Click any row — in the table or dispersion view — to open the document with the matched tokens highlighted.
  • Close reading at scale, three concepts in one query.

Tool 3 — Trends

Load snapshot → QLD_Election_Tweets_conc.

Themes across the spectrum.

Session 2

A real workflow

Four analysis tools. One question. 45 minutes.

The research question

Did female and male candidates tweet about different topical issues during the 2020 QLD election?

A few key moves I'll ask you to TRY THIS. For the rest, FOLLOW ALONG — try if you can, no pressure if you can't.

Fall behind, or a step doesn't work? Don't worry — sih.tools/wordflow → Materials → Session 2 checkpoint files has one for every phase (A → E). Download it and import it as a workspace to rejoin in ~30 seconds.

From here on, we're building — not just looking. Snapshot Mode can stay on; it only locks a tool's view once you load a snapshot into it.

Phase A · FOLLOW ALONG

Load, prepare, join

  1. Add the two CSV files as data blocks (tweets + candidate gender).
  2. Rename the long block via its menu icon → Rename.
  3. Delete unused columns via the column menu icon at the end of each column header. (optional)
  4. Set dtypes — username must be the same type in both, or the join won't match.
  5. Select tweets first, then the gender block — first pick = left table. Join on username (left join keeps every tweet) → tweets_with_gender.
  6. Click the joined block → see the gender column in the Data Viewer.

Data prep is part of the analysis. Don't rush.

Checkpoint A: Checkpoint_A.zip

Phase B · FOLLOW ALONG

Filter, then iterate Frequency ↔ Concordance

  1. Filter by gender = 'F' and gender = 'M' → tweets_female, tweets_male.
  2. Select both → Frequency tool, comparative mode (40 words, stopwords on).
  3. Click a topical word → Concordance opens with that word loaded.
  4. Read a few contexts. Back to Frequency. Pick another word. Repeat.
  5. Patterns to settle on: covid, case(s)?, cut(s)? — two themes (COVID, spending cuts).

The regex in C grew straight out of this iteration — built word by word.

Checkpoint B: Checkpoint_B.zip

Phase C · mixed

Multi-pattern regex → Add to Workspace → Trends

FOLLOW ALONG C-1: Concordance Regex mode, pattern covid|case(s)?|cut(s)?. Coloured matches. Dispersion view shows the spread; switch to Table view → Add to Workspace (one row per hit).

TRY THIS C-2: Trends on the matched block, grouped by term × gender. Click the covid/cases lines off in the legend, switch to a bar chart — male candidates mention cut(s) more than female. Set the time bin to weekly to sharpen it.

Checkpoint C: Checkpoint_C.zip

Phase D · TRY THIS

Topic modelling on two corpora

  1. Select both tweets_female + tweets_male. Topic Modelling. Target = 8, seed = 42. Run.
  2. BERTopic produces ~23 topics. Drag re-aggregation to 16 — bubbles spread.
  3. Colour mixing — solid = gender-dominant; blended = shared themes.
  4. Select 2-3 topics → Add to Workspace → per-gender child blocks under female and male.

Checkpoint D: Checkpoint_D.zip

Phase E · TRY THIS

Stack → final Trends

  1. Preprocessing → Stack the per-gender topic blocks from D → unified block (topic + gender columns preserved).
  2. Click stacked block → Trends. Group by topic (or gender × topic).
  3. Final view: selected topics, across the campaign, split by gender.

Four analysis tools. One corpus. One made-up hypothesis. One workflow.

Checkpoint E: Checkpoint_E.zip

Session 3.A

Repurpose the lens

Same tool, different question.

Demo 1 · out of the tool

Export the visualisation

  1. Open any analysis tool (e.g. the Frequency word cloud).
  2. Download icon at the top-right corner of each visualisation or table.
  3. Image views save PNG; list / table views save CSV.

Same pattern in Trends, Topic Modelling, Concordance, Quotation.

Demo 2 · through the tool

Filter the visualisation → new data block

  1. In Trends: click in the legend to hide / isolate lines.
  2. Click a data point — or click + Shift-click for a range.
  3. Click Add to Workspace — selection becomes a new data block.

Same pattern — Topic Modelling: select bubbles → Add to Workspace. Concordance: dispersion select → Add to Workspace.

Demo 3 · into the tool

Create a column → Trends becomes a histogram

  1. On Honi Soit articles: Preprocessing → Create column = word count per article.
  2. Trends tool — x-axis = the new word-count column.
  3. Numeric bucketing: 100 intervals.
  4. Switch chart from line to bar → histogram of article length.

Three takeaways from Wordflow

  1. Workspace + data block + graph — your project is a tree of derived data.
  2. Tools talk to each other — click a word, Add to Workspace, group. Stacking is what makes a workflow.
  3. Every tool is a lens — the analysis is shaped by how you shape the data, not by which tool you clicked.

The text flows. The lens changes.
