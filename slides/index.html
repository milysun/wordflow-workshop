Session 2

A real workflow

Six tools, one question, 45 minutes.

The research question

Did female and male candidates tweet about different topical issues during the 2020 QLD election?

Some moves I'll ask you to TRY THIS. Others WATCH ONLY.

If you fall behind, the Resources URL on the board has four checkpoint files. Load any one to rejoin in 30 seconds.

First: turn OFF Snapshot Mode in the top menu. We're building now.

Phase A · WATCH ONLY

Load, join, slice

  1. Join QLD tweets + candidate gender data.
  2. Accept the dtype normalisation.
  3. Filter to gender = F, then gender = M → two sub-corpora.
  4. Filter each to text contains "#" — keep just the hashtagged tweets.

Checkpoint α: session2-after-A.wordflow-workspace

Phase B · TRY THIS

Comparative Frequency → jump to Concordance

  1. Select both hashtagged blocks in the graph.
  2. Frequency tool → comparative mode (Juxtorpus) → 40 words → stopwords on.
  3. Save the list. Take a screenshot.
  4. Left-click a word. Watch what happens.

Tools talk to each other.

Phase C · mixed

Concordance — simple, then advanced

TRY THIS C-1: Run the search. Right-click results → Add as data block.

WATCH ONLY C-2: Switch to Regex. Pattern (covid|vaccine|mask). Coloured matches. Dispersion view. Click-and-drag to select. Add contexts as aggregated block.

Checkpoint γ: session2-after-C.wordflow-workspace

Phase D · WATCH ONLY

Trends on the aggregated block

  1. Time axis: tweet date. Bin: weekly.
  2. Group by gender — two lines.
  3. Swap to the matched-term column — three lines.

Same data. Swap one parameter. Different story.

Phase E · WATCH ONLY

Topic modelling → detach → back to Trends

  1. Topic Modelling. Target = 8 topics. Run.
  2. Re-aggregate to 5 topics (client-side, no re-run).
  3. Select 2-3 topics → Detach → new block.
  4. Back to Trends → group by topic.

Three things to remember

  1. Workspace + data block + graph — your project is a tree of derived data.
  2. Tools talk to each other — left-click a word, add as block, detach, group. Stacking is what makes a workflow.
  3. Every tool is a lens — the analysis is shaped by how you shape the data, not by which tool you clicked.

The text flows. The lens changes.
