LDaCA Wordflow v0.7.6 · 2026

Text analytics for researchers — without code.

LDaCA Wordflow is a single interface for concordance, frequency, trends, topic modelling, and comparative analysis across your text corpus.

Text data flows through stackable, single-purpose tools, and the meaning of an analysis comes from how you shape your data, not from the tool itself.
Launch Wordflow in Binder →
Download for macOS → Download for Windows →

Binder takes about a minute to spin up. The desktop app is recommended for serious work and as a backup if Binder is slow. The macOS installer is for Apple Silicon Macs.
